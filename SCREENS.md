# Kirana Khata: screens (v1.1)

- **Bottom tabs:** Khata (Customers | Suppliers, summary, collections, search/filter/sort) · Bills · Stock · More.
- **Customer / supplier page:** balance, due date, quick actions (Bill, Due date, Remind, Call, Statement, Bahi photo), entries with running balance, Credit/Payment (or Purchase/Payment) buttons.
- **New bill:** customer or walk-in, items (suggestions, plus HSN search by typing a code), GST/HSN per item, totals (Taxable / CGST / SGST on regular-GST shops), payment, Make bill → bill detail (Share PDF / Download / Delete).
- **Stock item:** unit, sale/purchase price, **GST / HSN** (schedule → HSN row → rate, incl./excl. GST), stock tracking, Stock in/out, history.
- **GST picker:** search by HSN code or keyword, schedule chips (Exempt, 5%, 18%, 28%, 40%, 3%, 1.5%, 0.25%), one row per HSN code with its product nature and rate.
- **More:** Galla, Reports, Expenses, Backup and restore, App lock, Shop details (name, address, phone, **GST registration**, **GSTIN**), Language.
